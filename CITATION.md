# Citing this software

Release title: Automated Photocatalysis Hardware Control. Version: 0.2.0. Release preparation date: 2026-10-20.

Use the exact version and archive identifier when citing the supplementary software. The authors, paper title, public repository URL, and archival DOI were not supplied and have not been invented. Complete `docs/release_metadata.json` and deposit the exact release in the chosen repository to obtain an identifier before adding a formal citation to the manuscript.

The preparation version number does not establish that this refactored release is byte-identical to the code used for the original experiments. The authors should identify the experiment-associated version and disclose this preparation in the manuscript or release notes.
