# Code availability

## Supplementary-software wording

The hardware-control source code, representative task inputs, coordinate and configuration files, installation instructions, and software-only validation materials are supplied as Supplementary Software 1 (version 0.2.0). Usage is governed by the accompanying LICENSE, which permits scholarly inspection and peer review and otherwise reserves rights. Vendor motion-controller runtime binaries must be obtained separately from the supplier. Robot-side programs and AGV assets are not included. The software-only demonstration does not reproduce chemical measurements or manuscript figures.

This wording describes the contents of the prepared archive. It must be aligned with the actual supplementary-file number and the journal's access requirements at submission. Once an archive/repository identifier exists, add its exact version-specific DOI or URL. No DOI, public accessibility, or editorial approval is asserted here.

## Policy basis

The preparation follows the documentation categories in Nature's [Guidelines for authors submitting code and software](https://media.nature.com/full/nature-cms/documents/GuidelinesCodePublication.pdf), accessed 2026-10-20: source/version details, installation and dependencies, demo/test data, timings, usage terms, and maintained access to the relevant version. This is a preparation reference; final requirements depend on the selected journal and editors.
